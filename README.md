# 🏔️ Summit Meditation
<mark>(https://summit-meditation.ai.studio))</mark>   
A serene, cinematic mindfulness experience that brings you to a peaceful mountain summit at sunrise. Designed for deep focus, breathwork, and tranquil contemplation with zero distractions.

---

### ✨ Key Features

- **Cinematic Camera Push-In**:
  - Continuous, slow camera movement gliding from an expansive high-altitude aerial vista into an intimate three-quarter shot.
  - Manual camera scrubber and push-speed controls (20s, 35s, 60s).
  - Cinematic framing modes (Full Screen, 16:9, 2.39:1 Anamorphic, 4:3 Academy) and sunrise color grading presets.

- **Procedural Ambient Soundscape (Web Audio API)**:
  - Generative mountain breeze and high-altitude wind synthesized entirely in real-time.
  - Periodic songbird chirps, resonant drone harmonies, and authentic Tibetan singing bowl chimes with zero external audio file dependencies.

- **Guided Rhythmic Breathwork**:
  - Proven breath patterns: **Box Breathing (4-4-4-4)**, **Relaxing 4-7-8**, **Coherent Resonant (5.5s)**, and **Awakening Pranayama**.
  - Interactive **Breath Cycle Goals** (4, 8, 12, 16, 20 cycles, or Freeflow) with automated singing bowl completion chimes.
  - Visual breath halo ring with live seconds countdown and phase animations.

- **Mindful Meditation Timer**:
  - Preset duration intervals (5m, 10m, 15m, 20m, or Open timer) with singing bowl chime reminders.

- **Atmospheric Visuals & Dynamic Canvas**:
  - Real-time procedural drifting cloud mist layers on HTML5 Canvas.
  - Inactivity auto-dimming controls for an immersive cinema mode.

---

### 🚀 Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Motion & Animations**: Motion (`motion/react`)
- **Audio Engine**: Native Web Audio API (procedural synthesis)
- **Icons**: Lucide React
